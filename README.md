# 🎤 PROJECT TTS

An offline Text-to-Speech web application built using FastAPI and pyttsx3.

## Features

- Convert text to speech
- Voice selection
- Speed control
- Volume control
- Modern web interface
- Offline functionality

## Technologies Used

- Python
- FastAPI
- pyttsx3
- HTML
- CSS

## Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Open:

```
http://127.0.0.1:8000
```
